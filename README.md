# E-commerce Website Backend

Welcome to the backend infrastructure of our e-commerce website, where we specialize in selling t-shirts! This project is built with a set of awesome technologies to ensure everything runs smoothly and efficiently.

## Tech Stack

### Backend Framework
- **Node.js**: This is the backbone of our application, providing the runtime to build fast and scalable network applications.
- **Express**: Our web framework, Express, helps us handle routing and middleware with ease.

### Database
- **MongoDB**: I used MongoDB for its flexibility and scalability, making it perfect for handling growing inventory of t-shirts.
- **Mongoose**: To interact with MongoDB, I used Mongoose, which makes working with our data easy.
